### 🛠 [ToolShare — Full-Stack Community Tool Sharing Platform](https://github.com/MayeraaSingh/ToolShare)
> A full-stack platform for listing, borrowing, and managing tools within a community.

**Key Features**
- REST APIs for tool lifecycle and user management built with Node.js and Express.js
- JWT authentication (httpOnly cookies) + Google OAuth via Firebase Authentication
- Responsive frontend with persistent state management
- MongoDB Atlas integration with rate limiting, security headers, and secure file upload handling
- Cloud infrastructure provisioned using Terraform

**Tech Stack:** `Node.js` `Express.js` `MongoDB Atlas` `Terraform` `Redux Toolkit` `Firebase`

🔗 **Repo:** [github.com/MayeraaSingh/ToolShare](https://github.com/MayeraaSingh/ToolShare)

### 🌐 [HoloScript — AI-Driven Holographic Scene System](https://github.com/holoscript-org/holoscript-mini)
> A multimodal system for voice-to-3D scene generation using LLMs with structured JSON outputs.

**Key Features**
- Natural language → scene graph pipeline capturing object position, scale, and orientation
- Gesture-based interaction using MediaPipe for real-time manipulation of scene elements
- POV-based frame simulation for user-perspective visualization
- 🌱 Actively contributing to this project as part of the **holoscript-org** open-source organization

**Tech Stack:** `Python` `OpenCV` `MediaPipe` `LLM APIs` `JSON`

🔗 **Repo:** [github.com/holoscript-org/holoscript-mini](https://github.com/holoscript-org/holoscript-mini)
